# D20X

Plataforma universal de RPG.

## Estrutura

- `index.html`: entrada e ficha de personagem.
- `ameacas.html` e `ameaca-ficha.html`: catálogo e fichas de ameaças.
- `multiplayer.html`: campanhas e tabletop.
- `dados/`: catálogos, descrições e referências de dados do RPG.
- `scripts/`: interface, fichas, inventário, rolagens, sincronização e tabletop.
- `estilos/`: folhas de estilo.
- `assets/`: imagens e outros recursos visuais existentes.
- `docs/`: instruções e notas de versões.
- `functions/`: API do Cloudflare Pages.

Os arquivos de entrada e configuração permanecem na raiz para manter os endereços públicos e a configuração do Cloudflare. Os módulos continuam separados para facilitar manutenção e atualizações.
